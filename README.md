# LogsGraph
Приложение предназначенно для просмотра большого количества графиков логов, которые записываются длительное время и привязываются ко времени.

В приложении реализован парсер данных, который позволяет загружать графики в различных текстовых форматах и с различной разметкой.

Для удобства отображения графиков, они разбиваются по отдельным графическим полям и их масштабирование и перемещение по временной шкале синхронизировано.

## Сборка приложения
Приложение написано на C# с графическим интерфейсом на WPF. Для сборки используется Visual Studio Community.
